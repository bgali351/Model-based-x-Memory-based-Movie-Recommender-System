Disclaimer: This repository just containts the result from both method using NDCG method to evaluate the prediction result, code using python for every method. 

This recommender system combine model-based and memory-based to get prediction result, there's use Naive Bayes Collaborative Filtering (NBCF) for model-based and neighbor selection use similarity function in Collaborative Filtering method. For the neighbor selection use two similarity function, there's Pearson Correlation Coefficient (PCC) and Improved Triangle’ Simmilarity Complemented with User Rating Preference (ITR).
